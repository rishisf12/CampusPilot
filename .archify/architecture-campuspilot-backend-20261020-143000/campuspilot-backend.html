CampusPilot Backend Pipeline

FastAPI + SQLModel + PostgreSQL + MCP observability — request flow, security boundaries, and data egress gates
Legend: Clients / Frontend FastAPI Application Database / Storage Infrastructure Auth / Access Control Background Jobs External Services
Edge (public)
  • React frontend on :5174 proxies /api → :8001
  • Backend is the only service with a route to the internet
  • CORS locked to FRONTEND_URL
Application (FastAPI)
  • Middleware: CORS → Maintenance → RequestMonitoring → Metrics
  • Lifespan bootstraps DB, flags, rollup, health, OppFeed scheduler
  • 20+ feature routers mount under /auth, /timetable, /exam, /admin/...
Security & Privacy
  • JWT HS256 + password_changed_at invalidation on reset
  • WebAuthn passkeys: public key stored, private key never leaves device
  • MCP egress gate redacts emails/JWTs/IPs before model context
  • tool_call_audit records every tool + LLM call (sent_to, bytes_out)
Data & Networks
  • PostgreSQL schemas: core / academic / social / telemetry
  • App-internal network (internal: true) blocks all outbound from DB/monitoring
  • LLM providers restricted to free allowlist: nvidia_nim, openrouter, ollama
